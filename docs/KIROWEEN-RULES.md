### Project Requirements
- **What to create:** a working software application built using Kiro (IDE, CLI, Web, and/or Kiro Crew), submitted into one category. Insufficient use of Kiro results in disqualification at the Judges' sole discretion.
  - Resurrection: bring a dead technology back to life.
  - Frankenstein: stitch together a chimera of technologies into one app, bringing together seemingly incompatible elements.
  - Skeleton Crew: a lean, flexible code template, shown with two distinct applications built from it.
  - Costume Contest: any app with a polished, haunting, unforgettable user interface.
- **Functionality:** the Project must install and run consistently on its intended platform and function as shown in the video or described in the text.
- **Platforms:** the Project must run on the platform specified in the Submission Requirements.
- **New Projects Only:** the Project must be newly created by the Entrant after the start of the Submission Period. Standard resources (frameworks, libraries, starter templates) are allowed, but any other pre-existing code or work must be disclosed. The work described and submitted must have been built during the Submission Period.
- **Third-party integrations:** you must be authorized to use any third-party SDK, API or data under its terms and licenses.

### Submission Requirements
- A Project built using Kiro that meets the Project Requirements.
- A URL to your functional application(s). If judges need login credentials, put them and instructions in the Devpost Submission Form.
- A text description of the features and functionality.
- A demonstration video that:
  - is less than three minutes (judges need not watch beyond three);
  - shows the Project functioning on the device it was built for;
  - is uploaded and publicly visible on YouTube, with the link in the submission form;
  - contains no third-party trademarks or copyrighted music or material without permission.
- A public URL to your code repository on GitHub (not GitLab or BitBucket).
  - It must contain all source code, assets and instructions needed for the project to function.
  - It must be public and open source, with an open source license file detectable and visible at the top of the repository page (About section).
  - It must contain the `/.kiro` directory at the root. Do NOT add `/.kiro` or its sub-folders to `.gitignore`; that could disqualify the Submission.
- The category and bonus category you are entering.
- Skeleton Crew only: two separate repo folders for the two applications.
- Startup Project Bonus Prizes only: founder confirmation, LinkedIn profile and startup website.
- Best Student Project Bonus Prize only: the student details above.
- Best Kiro Crew App Bonus Prize only: the GitHub URL of the Kiro Crew app and a description of its features.
- Social Blitz Bonus Prize only: the URL of your post with #KiroweenHackathon26 at the start.
- Bonus Blog Prize only: the URL of your public blog post.
- A write-up on how Kiro was used. Judges must understand how effectively you used Kiro. Show a next-level understanding of Kiro features, for example:
  - Kiro IDE, CLI, Web, Crew: how did they differ, if you tried several?
  - Custom agents: did you create or use any? In which Kiro app? How did they affect the build?
  - Agent hooks: which workflows did you automate, and how did the hooks improve development?
  - Spec-driven development: how did you structure your spec, how did it improve development, and how did it compare to vibe coding?
  - Steering docs: how did you use steering to improve Kiro's responses, and which strategy made the biggest difference?
  - MCP: what features or workflow improvements did extending Kiro enable that would otherwise be difficult or impossible?
  - Property-based testing (PBT): did it catch issues unit tests missed, and for which requirements did you enable it?
  - Kiro powers: which powers did you use for bundled best practices, and did you use third-party tooling or integrations you otherwise wouldn't have?

## 6. Judges and Criteria
The Sponsor and Administrator have sole right to determine eligibility and judging methods, which may use expert panels, peer review, automated AI-driven analysis, or any combination. Judges are chosen by the Sponsor, may be employees or third parties, may not all be listed, and may change. Judging may have one or more rounds and panels.

**Stage One:** pass/fail on baseline viability: the Project reasonably fits the theme and reasonably applies the required tools.

**Stage Two:** equally weighted criteria, 20% (10 points) each:
1. **Potential Impact:** does the project credibly solve a real problem for a real audience, based on what is demonstrated? How useful, intuitive and accessible is it? Would someone actually use it?
2. **Technological Implementation:** how thoroughly and skillfully does it use Kiro? Was there a thoughtful strategy to AI development? Was a variety of Kiro tools used impactfully? Does it show deep understanding of Kiro features? Was there experimentation?
3. **Design:** a complete, coherent product experience, not just a technical proof of concept. Intuitive, polished and intentional.
4. **Innovation/Idea:** how creative and novel is the concept, and does it differ from existing ones? Are unusual technologies or public resources (such as datasets) used or combined in a unique way?
5. **Presentation:** does the video show the project working end to end? Does the pitch say what problem is solved, for whom, and why it matters? Is it easy to follow, creative and memorable?

Prize selection:
- Overall Prizes: highest-scoring eligible Submissions across all categories.
- Category Prizes: highest-scoring eligible Submission in each category.
- Best Startup Project: highest-scoring eligible Submission with an eligible Startup profile.
- Best Ghost of Kiroween Past: highest-scoring eligible Submission with verified 2025 participation.
- Best Kiro Crew App: evaluated by the Kiro team from the top 50 eligible Submissions that include a Kiro Crew app GitHub repo link, on value/usefulness and technical innovation/idea.
- Best Student Project: highest-scoring eligible student Submission per category.
- Best Demo: highest-scoring eligible Submission on Presentation that is also in the top 10% of overall scores.
- Blog Post Bonus: the top 100 highest-scoring eligible Submissions with a qualifying public blog post. Leftover prizes are not awarded.
- Social Blitz: 5 eligible Submissions chosen by the Kiro team on post quality (original thought rather than AI writing, insights about Kiro, quality of images or video). Social profiles that do not match other submission details may be disqualified.

**Tie breaking:** tied Submissions are re-evaluated from scratch with a 20-point maximum per criterion. If still tied, add 10 points to the maximum each round until a winner emerges.
